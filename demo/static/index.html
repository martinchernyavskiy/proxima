Proxima

nearest-neighbor search, built from scratch

A vector search engine built from scratch in Rust. No managed API, no vector database. Type a natural-language query and a hand-written HNSW graph index finds the closest matches by meaning, not keywords, in milliseconds.

Works best as a descriptive question, like the examples above. It finds Wikipedia articles by meaning, not a general-knowledge chat assistant.

How it works

01
Embed: your query becomes a 384-dim vector (sentence-transformers)
02
Search: a hand-written HNSW graph, written in Rust, finds its nearest neighbors
03
Rank: the closest matching articles come back in milliseconds
