Proxima

nearest-neighbor search, built from scratch

This is the same core idea behind how Spotify finds a song like the one you're playing, how reverse image search works, and how a chatbot recalls the right memory: given one thing, find the most similar things out of millions, instantly.

Proxima does that from scratch, in Rust: no managed API, no vector database, no shortcuts for the search itself. Type a query below and watch a hand-written graph index called HNSW navigate a million Wikipedia articles to find the closest match by meaning, not keywords.

Works best as a descriptive question, like the examples above. It finds Wikipedia articles by meaning, not a general-knowledge chat assistant.

How it works

01
Embed: your query becomes a 384-dim vector (sentence-transformers)
02
Search: a hand-written HNSW graph, written in Rust, hops through real neighbors (watch it live, above) to find the nearest ones
03
Rank: the closest matching articles come back in milliseconds
